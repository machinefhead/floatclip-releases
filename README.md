## Portable edition

Extract the entire release ZIP to a folder and launch `FloatClip.exe`. No installer or extra C++ runtime is required. To exit, use the FloatClip notification-area icon. Normal operation does not require administrator privileges.

The download includes English/Slovenian usage instructions, changelog, license, privacy/support summaries and integrity checksums. The standalone Portable EXE is **not code-signed**; Windows SmartScreen may display a warning. Verify the official SHA256 checksum and do not disable Windows security protection to use the application.

**Windows 11 x64 only.** ARM64 operation has not been independently validated. Windows 10 is not an officially supported platform. UI text supports 10 localizations, with English as default.

## Microsoft Store edition

**FloatClip v1.0.0 is now published in Microsoft Store:** [Get FloatClip from Microsoft Store](https://apps.microsoft.com/detail/9NZ0NV55FBM1).

The Store edition is distributed as a separate MSIX package through Microsoft Store, with Store-managed installation and updates. The standalone Portable ZIP on this repository is a different distribution; do not upload or redistribute the unsigned Store submission MSIX. The Store edition intentionally omits the in-app Start with Windows and Restart as administrator options.

The public Store listing, not the source or release metadata repository, is the official installation channel for the Store package.

## Security, rights and privacy

FloatClip is **free proprietary software, not open source**. See [`LICENSE.txt`](LICENSE.txt) for conditions, including redistribution of the complete, unmodified Portable ZIP. This repository contains **release metadata only**, not application source code, build scripts, certificates or private test evidence.

FloatClip does not require an account and does not contain developer-operated cloud sync, advertisements, analytics or telemetry. It does not keep a separate clipboard-history database or upload clipboard contents. See the official privacy policy.
